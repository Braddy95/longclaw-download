Installation Guide

  1. Download the Installer

    Click the download button above. Your browser may show a warning since the file is not code-signed — click "Keep" or "Download anyway".

  2. Run the Setup Wizard

    Double-click LongclawSetup-x.x.x.exe. Windows SmartScreen may appear — click "More info" then "Run anyway". Follow the wizard (Next → Next → Install).

  3. Launch Longclaw

    After install, Longclaw launches automatically. A desktop shortcut is also created. The app opens in a native window — no browser needed.

  4. Sign In

    A running Refinitiv Eikon connection is required. If your Eikon account has been approved by the administrator (Bradley Jackson), you'll be logged in automatically. Only pre-approved Refinitiv accounts have access.

  5. Download Market Data

    Go to the Data tab to download instrument data from Refinitiv. Once downloaded, data is shared across all team members automatically.

Note: Longclaw requires an active Refinitiv Eikon connection and an approved Refinitiv account to sign in. Only accounts registered by the administrator (Bradley Jackson) will be granted access. All features (backtesting, analysis, reports) work offline once data has been downloaded. The app connects to a shared team database — strategies and data are synchronised across all users.
